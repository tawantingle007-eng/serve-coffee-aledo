# Serve Coffee & Goods — website preview

One-page concept site for Serve Coffee & Goods, 328 Old Annetta Rd, Aledo, TX.

**Live preview:** https://tawantingle007-eng.github.io/serve-coffee-aledo/

> This is an unsolicited design preview. Some content is placeholder/example material and may not match the shop exactly: the hero video (digitally rendered, not filmed at the shop), the logo, menu groupings and descriptive copy. Address, phone number, rating and review quotes come from the public Google Maps listing.

- Static site, no build step: `index.html`, `favicon.svg`, `media/`
- `_source/build/` — hero film shader + renderer, OG image renderer, Playwright verification script
- `_source/docs/` — design spec and build plan
